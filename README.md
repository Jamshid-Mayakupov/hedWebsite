# HURSHIDA ENTER DELUX website

Russian-language corporate website and content administration interface built with Vue 3, Vite, and Tailwind CSS.

## Local development

1. Install Node.js 22 and pnpm 10.
2. Copy `.env.example` to `.env.local` and replace the example HTTPS origins.
3. Run `pnpm install` and `pnpm dev`.

The public pages show honest unavailable states when an API origin is missing. The interactive Yandex map is optional and falls back to address and directions links.

## Required environment

- `VITE_SITE_URL`: canonical public origin.
- `VITE_API_BASE_URL`: product/news API origin.
- `VITE_AUTH_API_BASE_URL`: authentication API origin.
- `VITE_FILE_API_BASE_URL`: document API origin.
- `VITE_YANDEX_MAPS_API_KEY`: optional Yandex Maps key.

All production origins must use HTTPS. Backend authorization is mandatory; frontend route guards are only a usability layer.

## Project commands

- `pnpm lint`: ESLint for JavaScript and Vue files.
- `pnpm build`: production build.
- `pnpm check`: lint and production build.

## Deployment

Pushes to `main` are built and deployed by the GitHub Pages workflow in `.github/workflows/deploy.yml`. The workflow publishes `dist/` as a temporary Pages artifact and includes an SPA fallback for Vue Router routes.

`dist/` is intentionally ignored and must be generated by CI rather than committed.
